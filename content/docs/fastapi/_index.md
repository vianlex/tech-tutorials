# FastAPI 教程

FastAPI 是基于 Python 类型注解的高性能现代 Web 框架，基于 Starlette 与 Pydantic 构建，天然支持异步，并能在运行时自动完成数据校验。它开箱即用地提供交互式 Swagger UI 与 ReDoc 文档，让 API 的开发、测试与协作变得轻松高效。

## 章节 {.cards}

- [第一章：快速上手](/docs/fastapi/01-getting-started/) — 安装、第一个应用、uvicorn 运行与自动文档
- [第二章：请求与响应](/docs/fastapi/02-requests-responses/) — Pydantic v2 模型、参数校验与响应模型
- [第三章：依赖注入与中间件](/docs/fastapi/03-dependencies-middleware/) — Depends、中间件、CORS 与异常处理
- [第四章：认证与安全](/docs/fastapi/04-auth-security/) — OAuth2、JWT、密码哈希与权限控制
- [第五章：实战与部署](/docs/fastapi/05-deployment/) — SQLAlchemy CRUD、测试与 Docker 部署
