# Node.js 教程

Node.js 是基于 Chrome V8 引擎的 JavaScript 运行时，让 JavaScript 走出浏览器，用于构建高性能的服务端、命令行工具和前端构建工具。本教程从环境搭建到 Web 实战，带你系统掌握 Node.js 开发。

## 章节 {.cards}

- [第一章：环境搭建与基础](/docs/nodejs/01-environment/) — 安装/nvm、第一个程序、REPL、全局对象
- [第二章：模块系统与 npm](/docs/nodejs/02-modules/) — CommonJS/ESM、package.json、依赖管理
- [第三章：异步编程与事件循环](/docs/nodejs/03-async/) — 回调、Promise、async/await、事件循环
- [第四章：核心模块实战](/docs/nodejs/04-core/) — fs、path、http、stream、events
- [第五章：Web 开发与工程实践](/docs/nodejs/05-web/) — Express、中间件、REST API、调试部署
