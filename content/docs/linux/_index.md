# Linux 常用命令教程

Linux 是服务器和开发环境的主流操作系统，熟练使用命令行是工程师的基本功。本教程聚焦**高频命令**，重点讲透 `find`（文件查找）、`grep`（文本检索）、`journalctl`（日志分析）、`mount`（磁盘挂载）四个命令，并覆盖文件目录与系统管理等基础命令。

## 章节 {.cards}

- [第一章：文件与目录操作](/docs/linux/01-file-dir/) — ls/cd/cp/mv/rm、权限 chmod/chown、软硬链接
- [第二章：find 文件查找](/docs/linux/02-find/) — 按名称/类型/大小/时间查找、执行动作、常见场景
- [第三章：grep 文本检索](/docs/linux/03-grep/) — 正则匹配、上下文、递归搜索、常用选项
- [第四章：journalctl 日志分析](/docs/linux/04-journalctl/) — 查看服务日志、时间过滤、实时跟踪、按优先级筛选
- [第五章：mount 磁盘挂载](/docs/linux/05-mount/) — 挂载与卸载、fstab 自动挂载、常见文件系统与排错
