# TypeScript 教程

TypeScript 是 JavaScript 的**超集**，为 JS 增加了**静态类型系统**，让错误在编译期（而非运行时）就被发现，并提供强大的 IDE 提示与重构能力。本教程重点讲透 TS 的**结构化类型检查**这一核心思想，以及开发中的常用写法和重要知识点。

## 章节 {.cards}

- [第一章：基础与类型注解](/docs/typescript/01-basics/) — 安装、基本类型、类型推断、结构化类型检查
- [第二章：接口与类型别名](/docs/typescript/02-interface-type/) — interface 与 type、可选/只读、函数类型、索引签名
- [第三章：联合、交叉与收窄](/docs/typescript/03-union-narrowing/) — 联合类型、字面量类型、类型收窄、可辨识联合
- [第四章：泛型与工具类型](/docs/typescript/04-generics-utility/) — 泛型函数与约束、内置工具类型、类型守卫
- [第五章：高级类型与工程实践](/docs/typescript/05-advanced/) — 条件类型、keyof、映射类型、枚举、tsconfig 与最佳实践
