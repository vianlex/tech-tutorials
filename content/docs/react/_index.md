# React 教程

React 是当前最主流的**前端 UI 库**，以「组件化 + 声明式 + 单向数据流」为核心思想。本教程从 JSX 基础讲起，重点覆盖开发中最常用的知识点，并用详细实践例子讲透常用 Hooks，系统讲解组件间状态与值传递的各种方案，最后介绍 React 19 的新特性。

## 章节 {.cards}

- [第一章：基础与 JSX](/docs/react/01-basics/) — 组件、JSX、props、条件与列表渲染
- [第二章：状态与事件](/docs/react/02-state/) — useState 详解、事件处理、受控组件
- [第三章：副作用与 useEffect](/docs/react/03-effects/) — 依赖数组、清理函数、数据获取
- [第四章：常用 Hooks 详解](/docs/react/04-hooks/) — useRef、useMemo、useCallback、useContext、useReducer、自定义 Hook
- [第五章：进阶与 React 19](/docs/react/05-advanced/) — useTransition、use()、Actions、性能优化与最佳实践
- [第六章：组件间状态与值传递](/docs/react/06-component-communication/) — props、回调、状态提升、Context、状态管理库
