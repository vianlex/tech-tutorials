# Claude Code 使用教程

Claude Code 是 Anthropic 官方的终端 AI 编程助手（npm 包 `@anthropic-ai/claude-code`），能直接读取、编辑你的代码并在终端执行命令。本教程从安装、核心用法讲到 CLAUDE.md、权限、MCP 与子代理，帮助你快速把它用熟练。

## 章节 {.cards}

- [第一章：安装与快速上手](/docs/claude-code/01-installation/) — 安装、登录订阅、首次对话与基本交互
- [第二章：核心用法](/docs/claude-code/02-core-usage/) — 斜杠命令、@文件引用、图片输入、Git 集成、会话恢复
- [第三章：上下文与 CLAUDE.md](/docs/claude-code/03-claude-md/) — 项目记忆、CLAUDE.md 写法、分层配置与 /init
- [第四章：进阶能力](/docs/claude-code/04-advanced/) — 权限模式、MCP 服务器、Hooks、自定义斜杠命令与子代理
- [第五章：实战技巧与最佳实践](/docs/claude-code/05-best-practices/) — 典型工作流、大任务拆解、效率技巧与常见坑
