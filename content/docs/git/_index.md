# Git 使用教程

Git 是目前最流行的分布式版本控制系统，能够帮助个人或团队高效管理代码历史、并行协作开发。本教程从安装配置到分支协作、历史管理，带你系统掌握 Git 的核心命令与最佳实践。

## 章节 {.cards}

- [第一章：安装与基础操作](/docs/git/01-install-basics/) — 安装、初始配置、本地仓库基本命令
- [第二章：分支与合并](/docs/git/02-branch-merge/) — 分支管理、merge 与 rebase、冲突解决
- [第三章：远程协作](/docs/git/03-remote/) — remote、push/pull、SSH、Pull Request 工作流
- [第四章：历史管理与撤销](/docs/git/04-history/) — reset、revert、stash、reflog、cherry-pick
- [第五章：进阶与最佳实践](/docs/git/05-advanced/) — tag、submodule、Git Hooks、场景速查
