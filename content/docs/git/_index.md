# Git 使用教程

Git 是目前最流行的分布式版本控制系统，能够帮助个人或团队高效管理代码历史、并行协作开发。本教程从安装配置到分支协作、历史管理、常见问题排查，带你系统掌握 Git 的核心命令与最佳实践。

## 章节 {.cards}

- [第一章：安装与基础操作](/docs/git/01-install-basics/) — 安装、初始配置、diff/show/log 进阶、alias 别名、日常命令速查
- [第二章：分支与合并](/docs/git/02-branch-merge/) — 分支管理、merge 与 rebase、冲突解决、同步开发实战流程（含 feature/hotfix/release）
- [第三章：远程协作](/docs/git/03-remote/) — remote、push/pull、SSH/HTTPS、PR 完整生命周期、代理与多账号
- [第四章：历史管理与撤销](/docs/git/04-history/) — reset/revert、stash、reflog、cherry-pick、交互式变基、bisect 二分
- [第五章：进阶与最佳实践](/docs/git/05-advanced/) — tag、submodule/subtree、Hooks、worktree、LFS、commit 规范
- [第六章：常见问题与故障排查](/docs/git/06-faq/) — 误删恢复、推送被拒、敏感信息清理、换行符、性能优化等 30+ FAQ
