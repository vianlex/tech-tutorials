# Groovy 教程

Groovy 是一门运行在 JVM 上的动态（可选静态）语言，语法兼容 Java 且更简洁灵活。它被广泛用于 Gradle 构建脚本、Jenkins Pipeline 以及各类自动化与脚本任务。

## 章节 {.cards}

- [第一章：环境搭建与基础语法](/docs/groovy/01-setup-basics/) — SDKMAN 安装、groovyConsole、变量、类型、运算符、GString
- [第二章：集合与闭包](/docs/groovy/02-collections-closures/) — List/Map、each/collect/findAll、闭包语法与参数、方法引用
- [第三章：面向对象](/docs/groovy/03-oop/) — 类、trait、POGO 特性、运算符重载、@CompileStatic
- [第四章：元编程与高级特性](/docs/groovy/04-metaprogramming/) — ExpandoMetaClass、MOP、@Delegate 等 AST 转换、GPath、XML/JSON 处理
- [第五章：实战应用](/docs/groovy/05-practice/) — Grape 依赖、脚本编写、Gradle 构建脚本、Jenkins Pipeline 基础
