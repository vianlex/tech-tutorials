# Spring 教程

Spring 是 Java 生态中最流行的企业级开发框架。本教程从核心概念讲起，逐步深入到 Spring Boot 微服务开发，最后覆盖异步、缓存与安全等企业级应用必备主题。

## 章节 {.cards}

- [第一章：Spring 概述与 IoC](/docs/spring/01-intro-ioc/) — 框架定位、依赖注入、Bean 生命周期、作用域、循环依赖、条件装配、事件机制
- [第二章：AOP 面向切面编程](/docs/spring/02-aop/) — 代理原理、切点表达式、通知类型与自调用问题、引介增强
- [第三章：Spring MVC](/docs/spring/03-mvc/) — 请求链路、参数绑定、数据校验、统一异常、异步 MVC、CORS
- [第四章：Spring Boot 快速上手](/docs/spring/04-boot/) — 自动配置、起步依赖、配置体系、内嵌服务器、Actuator、Native Image
- [第五章：数据访问与事务](/docs/spring/05-data/) — JDBC、JPA、声明式事务、事务传播与失效清单、Spring Data Redis
- [第六章：异步、缓存与调度](/docs/spring/06-async-cache-scheduler/) — @Async、TaskExecutor、@Scheduled、Spring Cache 抽象
- [第七章：Spring Security 安全框架](/docs/spring/07-security/) — 认证、授权、CSRF、JWT、密码加密、方法安全
