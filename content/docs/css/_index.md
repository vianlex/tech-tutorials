# CSS 教程

CSS（层叠样式表）是控制网页外观的语言，决定元素的大小、颜色、间距、排版与布局。本教程**重点讲透两个核心**——**盒子模型**（理解元素尺寸与间距的基础）和 **Flex 布局**（现代一维布局的主力），并覆盖选择器、定位、响应式与工程实践，配图说明关键概念。

## 章节 {.cards}

- [第一章：选择器与层叠](/docs/css/01-selectors/) — 选择器优先级、层叠规则、继承与盒模型总览
- [第二章：盒子模型详解](/docs/css/02-box-model/) — content/padding/border/margin、box-sizing、外边距合并
- [第三章：定位与文档流](/docs/css/03-positioning/) — 文档流、position 五种取值、层叠上下文
- [第四章：Flex 布局详解](/docs/css/04-flexbox/) — 主轴交叉轴、容器与项目属性、常见布局实战
- [第五章：响应式与变量](/docs/css/05-responsive/) — 媒体查询、rem/vw、CSS 变量、工程化最佳实践
