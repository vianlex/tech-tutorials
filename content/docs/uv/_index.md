# Uv 教程

**uv** 是 Astral 团队（Ruff 的作者）用 Rust 打造的**极速 Python 包管理与项目管理工具**。它把 `pip`、`venv`、`pyenv`、`pipx`、`poetry`、`pdm` 等一整条工具链的能力，统一进了一个单一二进制文件，速度比 pip 快 10–100 倍。

## 章节 {.cards}

- [第一章：简介与安装](/docs/uv/01-intro/) — 为什么用 uv、安装方式、与 pip/poetry 的对比
- [第二章：Python 与虚拟环境管理](/docs/uv/02-python-venv/) — 管理 Python 版本、创建与激活虚拟环境
- [第三章：依赖管理](/docs/uv/03-dependencies/) — uv add/remove、sync、lock、uv pip 兼容模式
- [第四章：项目管理](/docs/uv/04-project/) — uv init、pyproject.toml、uv run、脚本与工具
- [第五章：进阶与常见问题](/docs/uv/05-advanced/) — workspace、锁文件、构建发布、排坑
