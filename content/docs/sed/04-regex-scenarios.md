# 正则与实用场景

sed 的威力来自正则表达式。本章先快速过一遍 sed 支持的常用符号，再用一批真实场景把你「学到马上能用」的套路固化下来。

## sed 正则速览 {#regex-overview}

sed 默认使用**基础正则（BRE）**，特殊字符默认是「字面量」，需要加 `\` 才激活元字符含义。常用符号：

| 符号 | 含义 | 示例 |
|------|------|------|
| `.` | 任意单个字符 | `c.t` 匹配 `cat`、`cbt` |
| `*` | 前一项重复 0 次或多次 | `ab*c` 匹配 `ac`、`abbc` |
| `\+` | 前一项重复 1 次或多次（BRE 需转义） | `ab\+c` 匹配 `abc` |
| `\?` | 前一项出现 0 或 1 次 | `colou\?r` 匹配 `color`/`colour` |
| `^` | 行首 | `^#` 行以 # 开头 |
| `$` | 行尾 | `;$` 行以 ; 结尾 |
| `[abc]` | 字符集合 | `[0-9]` 数字 |
| `[^abc]` | 取反集合 | `[^0-9]` 非数字 |
| `\(...\)` | 分组（用于反向引用） | `\(ab\)\1` 匹配 `abab` |
| `\{m,n\}` | 重复 m 到 n 次（BRE 需转义） | `[0-9]\{2,4\}` |

> GNU sed 用 `-E` 可切换到扩展正则（ERE），此时 `()`、`+`、`?`、`{}` 不用再加 `\`，写起来更顺手。详见第五章。

## 贪婪匹配要注意 {#greedy}

sed 的 `.*` 是**贪婪**的——会尽量往后匹配到最后一个符合的位置：

```bash
# 本意可能只想去掉第一个 <b>，但贪婪会匹配到最后一个 </b>
echo "<b>粗体</b> 文本 <b>再粗</b>" | sed 's/<b>.*<\/b>//'
# 输出：   （整段都被吃掉了！）

# 改进：用 [^<]* 限制不匹配 <，只去掉第一个标签
echo "<b>粗体</b> 文本 <b>再粗</b>" | sed 's/<b>[^<]*<\/b>//'
# 输出： 文本 <b>再粗</b>
```

记住：**用 `[^x]*` 替代 `.*` 可以避免跨越多段**，这是处理带分隔符文本的关键技巧。

## 实战：批量替换文件 {#batch-replace}

最常见的需求——把项目里一批文件的关键词统一改掉：

```bash
# 当前目录下所有 .txt 文件，把旧域名换成新域名（先预览，不加 -i）
sed 's/old.example.com/new.example.com/g' *.txt

# 确认无误后原地替换（GNU sed 直接 -i）
sed -i 's/old.example.com/new.example.com/g' *.txt

# 递归处理（find + sed，仅改 .conf 文件）
find . -name '*.conf' -exec sed -i 's/DEBUG/RELEASE/g' {} +
```

## 实战：处理配置文件 {#config-file}

清理和改写配置文件是 sed 的拿手好戏：

```bash
# 1) 删除所有注释行（以 # 或 ; 开头）
sed -e '/^[ \t]*#/d' -e '/^[ \t]*;/d' nginx.conf

# 2) 删除注释行和空行，得到「干净的配置」
sed -e '/^[ \t]*#/d' -e '/^[ \t]*;/d' -e '/^[ \t]*$/d' nginx.conf

# 3) 修改某个配置项的值（如把 port 改成 8080）
sed -i 's/^\(port[ \t]*=\).*/\1 8080/' app.ini
# 说明：分组 \1 保留 "port =" 本身，只替换后面的内容

# 4) 给被注释掉的配置项取消注释（启用）
sed -i 's/^#\s*\(server_name\)/\1/' nginx.conf
```

## 实战：删除注释行 {#delete-comments}

```bash
# 只删除「整行都是注释」的行（保留行内 # 后面的正常内容）
sed '/^[ \t]*#/d' script.sh

# 删除行内注释（# 及其后面的内容），但保留以 #! 开头的 shebang
sed -E '/(^#!|#)/!{s/#.*//}' script.sh
# 更稳妥的写法：保留 shebang，其余行的 # 注释去掉
sed -E '/^#!\/bin\/bash/! s/#.*$//' script.sh
```

## 实战：提取日志字段 {#extract-log}

从日志里抠出想要的字段，比 awk 轻量很多：

```bash
# 假设日志：192.168.1.1 - - [06/Sep/2024] "GET /api" 200
# 只提取 IP 和状态码
echo '192.168.1.1 - - [06/Sep/2024] "GET /api" 200' \
  | sed -E 's/^([0-9.]+) .* "([A-Z]+) .*" ([0-9]+)$/\1 \2 \3/'
# 输出：192.168.1.1 GET 200

# 从 access.log 提取所有 404 的请求路径
sed -nE 's/.*"GET ([^ ]+) HTTP.*" 404 .*/\1/p' access.log

# 把时间戳从 "06/Sep/2024" 改成 "2024-09-06"
echo "06/Sep/2024" | sed -E 's#([0-9]{2})/([A-Za-z]+)/([0-9]{4})#\3-\2-\1#'
# 输出：2024-Sep-06（月份名需另用表替换，这里演示位置重排）
```

## 实战：给行首加内容 {#prefix-line}

```bash
# 给每行行首加 "=> "
echo -e "苹果\n香蕉" | sed 's/^/=> /'
# 输出：
# => 苹果
# => 香蕉

# 给所有非空行加行号前缀（用 = 命令打印行号，再合并）
echo -e "a\nb\nc" | sed '=' | sed 'N; s/\n/: /'
# 输出：
# 1: a
# 2: b
# 3: c

# 给标题行（含 #）前加空行做分隔
sed '/^#/ i\ ' docs.md
```

## 实战：给文件加行号 {#number-lines}

```bash
# 用 sed 的 = 命令打印行号，再与内容合并
sed '=' data.txt | sed 'N; s/\n/ /'
# 输出示例：
# 1 hello
# 2 world

# 更紧凑：用 nl 命令（非 sed，但常配合）
nl -ba data.txt
```
