# Maven 教程

Maven 是 Java 生态最主流的**项目构建与依赖管理工具**，用「约定优于配置（Convention over Configuration）」统一了项目结构、依赖坐标、构建生命周期。本教程从零讲起，覆盖日常开发与工程化所需的全部核心知识。

## 章节 {.cards}

- [第一章：基础与坐标](/docs/maven/01-basics/) — 安装、目录约定、GAV 坐标、仓库与 settings
- [第二章：依赖管理](/docs/maven/02-dependencies/) — scope、传递依赖、冲突仲裁、BOM
- [第三章：生命周期与插件](/docs/maven/03-lifecycle/) — 三套生命周期、核心插件、自定义绑定
- [第四章：多模块工程](/docs/maven/04-multimodule/) — 聚合、继承、dependencyManagement
- [第五章：实战与常见问题](/docs/maven/05-practice/) — 打包、跳过测试、profile、跳过、排坑
