# OpenCode 使用教程

OpenCode 是 SST/Anomaly 团队开源的 AI 编程 Agent（官网 opencode.ai），可免费使用内置模型，也能连接任意厂商的 LLM（Claude、GPT、Gemini 等）。它以终端 TUI、桌面 App、IDE 扩展三种形态存在，本教程从安装到进阶，带你完整掌握它的用法。

## 章节 {.cards}

- [第一章：简介与安装](/docs/opencode/01-intro-install/) — 是什么、三形态对比、各平台安装与版本验证
- [第二章：快速上手](/docs/opencode/02-getting-started/) — 配置 Provider（/connect 与 auth login）、/init 生成 AGENTS.md、第一个对话
- [第三章：核心用法](/docs/opencode/03-core-usage/) — Plan/Build 模式切换、@文件引用、图片输入、/undo 与会话管理
- [第四章：配置与自定义](/docs/opencode/04-config/) — opencode.json、模型选择、自定义 agent、规则文件、主题与快捷键
- [第五章：进阶与最佳实践](/docs/opencode/05-advanced/) — CLI 非交互 run、serve 无头 API、GitHub agent、多会话并行与效率技巧
