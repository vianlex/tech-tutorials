# 函数、数组与实战

本章补充 awk 的内置函数、深入关联数组的实战用法，并通过解析 CSV/日志、`sort` 排序等案例把前面所学串起来，最后给出一份速查表。

## 常用内置函数 {#builtin-func}

| 函数 | 作用 | 示例 |
|------|------|------|
| `length(s)` | 字符串长度 | `length("awk")` → `3` |
| `substr(s,p,n)` | 从位置 `p` 取 `n` 个字符 | `substr("hello",2,3)` → `ell` |
| `split(s,a,sep)` | 用 `sep` 切分 `s` 到数组 `a` | `split("a,b",a,",")` |
| `toupper(s)` | 转大写 | `toupper("abc")` → `ABC` |
| `tolower(s)` | 转小写 | `tolower("ABC")` → `abc` |
| `sprintf(fmt,...)` | 按格式返回字符串（不打印） | `sprintf("%.2f", 3.1)` |

字符串处理示例：

```bash
# 取每行前 3 个字符，并转大写
echo -e "apple\nbanana" | awk '{ print toupper(substr($0,1,3)) }'
# 输出：
# APP
# BAN
```

`split` 把字符串拆进数组：

```bash
echo "2024-01-15" | awk '{
  split($0, d, "-")
  print "年=" d[1] " 月=" d[2] " 日=" d[3]
}'
# 输出：
# 年=2024 月=01 日=15
```

`sprintf` 构造格式化字符串（常用于拼结果）：

```bash
echo "0.1" | awk '{ s = sprintf("金额:%.2f元", $1); print s }'
# 输出：
# 金额:0.10元
```

## 关联数组进阶：分组汇总 {#array-group}

关联数组（键为任意字符串）是 awk 做统计的核心。先累加，再遍历输出。遍历顺序不定，需要有序时配合 `sort`。

```bash
# 按第 1 列分组，对第 2 列求和
echo -e "A 10\nB 5\nA 20\nB 15" | awk '{ a[$1]+=$2 } END { for (k in a) print k, a[k] }'
# 输出：
# A 30
# B 20
```

同时记录「分组个数」与「分组和」：

```bash
echo -e "A 10\nA 20\nB 5" | awk '
{ sum[$1]+=$2; cnt[$1]++ }
END { for (k in sum) printf "%s 平均=%.1f (n=%d)\n", k, sum[k]/cnt[k], cnt[k] }'
# 输出：
# A 平均=15.0 (n=2)
# B 平均=5.0 (n=1)
```

## 用 `-v` 传参做灵活脚本 {#var-script}

把阈值、分隔符等作为参数传入，避免硬编码：

```bash
# 只统计金额 >= 指定阈值的城市总和
limit=40
echo -e "北京 30\n上海 60\n广州 50" | awk -v t="$limit" '$2>=t { sum+=$2 } END { print "达标总额:", sum }'
# 输出：
# 达标总额: 110
```

## 实战：解析 CSV {#csv}

CSV 用逗号分隔，注意字段内可能含逗号（被引号包裹），这里以规范 CSV 为例。

```bash
# 输入：name,score，跳过表头，求每人的等级
echo -e "name,score\nTom,92\nLucy,58\nBob,75" | awk -F',' '
NR>1 {
  if ($2 >= 60) lv="及格"; else lv="不及格"
  print $1 " -> " $2 " (" lv ")"
}'
# 输出：
# Tom -> 92 (及格)
# Lucy -> 58 (不及格)
# Bob -> 75 (及格)
```

## 实战：解析日志（访问统计） {#log}

常见访问日志形如 `IP - - [时间] "方法 路径 协议" 状态码 大小`。

```bash
# 用空格分隔，第 1 列是 IP，第 9 列是状态码
# 统计每个状态码出现次数
echo -e "1.1.1.1 - - [] GET / 200 123\n2.2.2.2 - - [] GET / 404 50\n1.1.1.1 - - [] POST / 200 80" \
| awk '{ code[$9]++ } END { for (c in code) print "状态码 " c ": " code[c] " 次" }'
# 输出：
# 状态码 200: 2 次
# 状态码 404: 1 次
```

## 配合 sort 排序输出 {#sort}

awk 遍历顺序不确定；要按值排序，把结果交给 `sort`。

```bash
# 统计每个城市的销售额，并按销售额降序排序
echo -e "北京 100\n上海 80\n北京 50\n上海 120" \
| awk '{ c[$1]+=$2 } END { for (k in c) print c[k], k }' \
| sort -rn
# 输出：
# 200 上海
# 150 北京
```

> 这里先打印「值 键」，再让 `sort -rn`（数值降序）排序，可读性更好。

## 注意事项 {#notes}

- 未初始化变量的值为 `0`（数值）或空串（字符串），计数 `c++` 可直接用，无需先 `c=0`。
- 浮点比较注意精度：`$1 > 0.1` 一般没问题，但避免用 `==` 比较浮点数。
- 改动 `FS`/`OFS` 最好在 `BEGIN` 里设置，避免首行被旧分隔符切错。
- 正则写在 `/.../` 中，特殊字符需转义；字段匹配用 `$1 ~ /re/` 更精确。
- 大文件处理 awk 很高效（流式、单遍扫描），但超大数据建议先 `grep` 过滤再交给 awk。

## 速查表 {#cheatsheet}

| 需求 | 写法 |
|------|------|
| 打印某列 | `awk '{print $1}'` |
| 指定分隔符 | `awk -F','` 或 `BEGIN{FS=","}` |
| 取最后一列 | `awk '{print $NF}'` |
| 过滤条件行 | `awk '$2>80'` |
| 正则匹配整行 | `awk '/ERROR/'` |
| 字段匹配 | `awk '$1 ~ /^[0-9]+$/'` |
| 加行号 | `awk '{print NR, $0}'` |
| 多文件独立行号 | `awk 'FNR==1{...}' f1 f2` |
| 求和 | `awk '{s+=$1} END{print s}'` |
| 计数 | `awk 'END{print NR}'` |
| 平均值 | `awk '{s+=$1;n++} END{print s/n}'` |
| 分组求和 | `awk '{a[$1]+=$2} END{for(k in a)print k,a[k]}'` |
| 格式化输出 | `awk '{printf "%-10s %d\n", $1, $2}'` |
| 传外部变量 | `awk -v t=80 '$1>t'` |
| 表头(跳过首行) | `awk 'NR>1{...}'` |
| 排序输出 | `... | sort -rn` |

## 小结 {#summary}

本章掌握了内置字符串函数、关联数组分组汇总、`-v` 参数化，以及解析 CSV/日志、配合 `sort` 排序的实战套路。至此你已具备用 awk 处理日常文本分析、日志统计、数据清洗的能力。建议从「提取列 → 过滤 → 统计 → 分组」逐步组合，遇到复杂需求再写成多行 awk 脚本。
