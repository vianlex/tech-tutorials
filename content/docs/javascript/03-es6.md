# ES6+ 现代特性

ES2015（ES6）是 JavaScript 里程碑式升级，之后每年都有增量特性。本章聚焦最常用的现代特性，并尽量揭示底层机制。

## 解构赋值 {#destructuring}

解构让「从数组/对象批量提取值」变得简洁，还支持嵌套、重命名与默认值。

```javascript
// 数组解构
const [first, second, ...rest] = [1, 2, 3, 4, 5];
console.log(first, rest);   // 1  [3,4,5]

// 嵌套解构
const user = { name: 'Alice', profile: { addr: { city: 'BJ' } } };
const { profile: { addr: { city } } } = user;
console.log(city);          // "BJ"

// 对象解构 + 重命名 + 默认值
const { name: username, age: userAge = 18 } = user;
```

### 交换变量与函数参数解构 {#swap-params-destructure}

```javascript
// 不借助临时变量交换
let x = 1, y = 2;
[x, y] = [y, x];

// 函数参数解构：直接拆解传入对象
function createUser({ name, age = 18, role = 'guest' } = {}) {
    return { name, age, role };
}
createUser({ name: 'Tom' }); // { name:'Tom', age:18, role:'guest' }
```

## 模板字符串 {#template-strings}

模板字符串用反引号包裹，支持插值、多行，以及更强大的**标签模板**。

```javascript
const name = 'Alice';
const greeting = `Hello, ${name}!`;   // 反引号 + ${}
const html = `
  <div>
    <p>多行内容</p>
  </div>
`;
```

### 标签模板（tagged template） {#tagged-template}

标签函数「拦截」模板的片段与插值，常用于转义、i18n：

```javascript
function tag(strings, ...values) {
    console.log('片段:', strings);   // ["单价 ", " 元"]
    console.log('插值:', values);    // [9.9]
    return strings.reduce((acc, s, i) => acc + (values[i - 1] ?? '') + s, '');
}
tag`单价 ${9.9} 元`;

// 实战：HTML 转义防 XSS
function safe(strings, ...values) {
    const esc = (v) => String(v).replace(/[&<>"]/g, c =>
        ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;' }[c]));
    return strings.reduce((acc, s, i) => acc + esc(values[i - 1] ?? '') + s, '');
}
safe`<div>${'<script>x</script>'}</div>`;  // 转义后安全字符串
```

## 展开与剩余运算符 {#spread-rest}

`...` 用于展开可迭代对象（spread）或收集剩余项（rest），二者符号相同语义相反。

```javascript
const arr1 = [1, 2, 3];
const arr2 = [...arr1, 4, 5];     // [1,2,3,4,5]
const merged = { ...user, city: 'Beijing' };  // 浅合并（后者覆盖前者）

function sum(...numbers) { return numbers.reduce((a, b) => a + b, 0); }
sum(1, 2, 3, 4);  // 10
```

> [!NOTE]
> 展开是**浅拷贝**，嵌套对象仍共享引用。深拷贝可用 `structuredClone()` 或第三方库。

## 可选链与空值合并 {#optional-chaining-nullish}

```javascript
const user = { profile: { name: 'Alice' } };
user.profile?.name;        // "Alice"
user.contact?.email;       // undefined（不会抛错）
```

### 边界：0、空串、false {#nullish-boundary}

```javascript
const score = 0, label = '';
score ?? 100;     // 0   （保留 0）
label ?? '默认';   // ""  （保留空串）
score || 100;     // 100 ❗（|| 把 0 当假值，常造成 bug）
```

## 默认参数 {#default-params}

```javascript
function greet(name = 'World') {
    console.log(`Hello, ${name}`);
}
greet();         // "Hello, World"
greet('Alice');  // "Hello, Alice"

// 默认值可引用前面的参数；注意默认参数有独立作用域（见第二章参数机制）
function repeat(text, times = text.length) {
    return text.repeat(times);
}
repeat('ab');     // "abab"
```

## 模块（ES Modules） {#modules}

### ESM 与 CommonJS 区别 {#esm-vs-cjs}

| 特性 | ES Modules | CommonJS |
|------|-----------|----------|
| 语法 | `import`/`export` | `require`/`module.exports` |
| 加载 | 静态（编译期） | 动态（运行期） |
| 绑定 | 实时只读绑定 | 值的拷贝 |

```javascript
// math.js
export const PI = 3.14;
export function add(a, b) { return a + b; }
export default function multiply(a, b) { return a * b; }

// main.js
import multiply, { add, PI } from './math.js';
```

### 静态特性与 tree-shaking {#tree-shaking}

`import` 是**静态**的（必须顶层、不能放 `if` 里），让打包工具在编译期分析依赖、剔除未使用导出（tree-shaking）：

```javascript
// ❌ ESM 中不合法：import 必须顶层静态出现
// if (cond) import('./x.js');
```

### 动态 import() {#dynamic-import}

需按需加载时用动态 `import()`（返回 Promise）打破静态限制：

```javascript
button.onclick = async () => {
    const module = await import('./heavy-chart.js');
    module.render(data);
};
```

## 类（class） {#class}

`class` 本质是**基于原型的语法糖**，不引入新类型。理解它与原型链关系很关键。

```javascript
class Animal {
    constructor(name) { this.name = name; }
    speak() { console.log(`${this.name} makes a sound`); }
}
const a = new Animal('X');
Animal.prototype.speak === a.speak;  // true（方法在原型上）
```

### getter / setter 与静态、私有成员 {#getter-setter-static}

```javascript
class Circle {
    static PI = 3.14;
    #radius = 0;                  // 私有字段 #（外部不可访问）

    constructor(r) { this.#radius = r; }
    get area() { return Circle.PI * this.#radius ** 2; }  // getter
    set radius(r) { if (r > 0) this.#radius = r; }       // setter
}
const c = new Circle(2);
c.area;        // getter 调用 ≈ 12.56
// c.#radius;   // ❌ 私有字段外部不可访问
```

### 继承与 super {#extends-super}

```javascript
class Dog extends Animal {
    constructor(name, breed) {
        super(name);             // 须先调用 super 才能用 this
        this.breed = breed;
    }
    speak() {
        super.speak();           // 调用父类方法
        console.log(`${this.name} barks`);
    }
}
```

> [!NOTE]
> `super` 本质是对「父类原型」的引用；子类构造函数中必须先 `super()` 再访问 `this`。

## Symbol 与迭代器 {#symbol-iterator}

`Symbol` 承载语言内部「钩子」——**知名符号**（如 `Symbol.iterator`、`Symbol.toPrimitive`）。

### 可迭代协议与 for...of {#iterable-protocol}

`for...of` 能遍历任何实现**可迭代协议**的对象：须部署 `Symbol.iterator` 方法，返回带 `next()` 的迭代器。

```javascript
const obj = { a: 1, b: 2 };
obj[Symbol.iterator] = function* () {
    for (const key of Object.keys(this)) yield [key, this[key]];
};
for (const [k, v] of obj) console.log(k, v);  // a 1 / b 2
```

### 生成器与 yield {#generator-yield}

生成器（`function*`）按需产出值，`yield` 暂停、下次 `next()` 恢复：

```javascript
function* gen() {
    yield 1;
    yield 2;
    return 'done';
}
const it = gen();
it.next();   // { value: 1, done: false }
it.next();   // { value: 2, done: false }
it.next();   // { value: 'done', done: true }
```

## Map / Set / WeakMap / WeakSet {#collections}

传统对象作映射有诸多限制（键只能是字符串/Symbol、`size` 需手动维护）。ES6 提供专业集合类型。

```javascript
// Map：键任意类型，保持插入顺序
const m = new Map();
m.set('a', 1).set({}, '任意键');
m.size;       // 2

// Set：唯一值集合
const s = new Set([1, 1, 2, 3]);  // {1,2,3}

// WeakMap：键仅对象且弱引用（不阻止 GC），适合挂元数据
const wm = new WeakMap();
wm.set(obj, 'meta');   // obj 被回收时记录自动消失
```

> [!TIP]
> 需「对象可回收的元数据」用 `WeakMap`；需缓存/去重/频繁增删用 `Map`/`Set`。

## Proxy 与 Reflect 简介 {#proxy-reflect}

`Proxy` 可拦截对目标对象的任意操作（读、写、删、调用），是 Vue 3 响应式等框架基石。

```javascript
const target = { count: 0 };
const proxy = new Proxy(target, {
    get(t, key, receiver) {
        console.log('读取', key);
        return Reflect.get(t, key, receiver);
    },
    set(t, key, value, receiver) {
        console.log('写入', key, value);
        return Reflect.set(t, key, value, receiver);
    }
});
proxy.count;     // 控制台打印「读取 count」
proxy.count = 5; // 控制台打印「写入 count 5」
```

> [!NOTE]
> `Reflect` 提供与 Proxy 拦截器一一对应的静态方法，二者配合保证「默认行为」被正确转发。
